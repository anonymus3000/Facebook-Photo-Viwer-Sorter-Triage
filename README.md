# Facebook-Photo-Viewer-Sorter-Triage
Allows you to quickly sort and "triage" lots of Facebook photos from a list of URLs
#How to run it
1. Download all files
2. Extract them into one folder
3. Open terminal in that folder and run: "npm install"
4. Then run: "npm start"
#How to sort
1. Upload the txt file containing all the facebook photo links
2. Use keyboard to view, discard or save photos URLs into a separate list
The keybind legend is on the right hand side
Highliy recommend to login into facebook, as otherwise it will constatly give you a "Please login" pop up
#How to get URLs List
1. Download "Tampermonkey" extension for chrome
2. Enable developer mode in chrome extension settings
3. Enable "Allow user scripts" in Tampermonkey extension settings
4. Download Facebook Photo Link Collector script for Tampermokey from here:
5. Run the script of the target Facebook photo page(follow instruction on the website above)
